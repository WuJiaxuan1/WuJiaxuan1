# 大学生职业规划智能体 · Career Pathfinder

## 项目概况

面向高校就业场景，将“简历上传 → 学生画像 → 人岗匹配 → 职业路径 → AI 咨询 → 报告生成”组织为一个应用流程。

**我的角色：独立开发。** 项目围绕学生画像、岗位匹配、检索增强咨询和报告生成构建职业规划应用。

[查看项目代码](https://github.com/WuJiaxuan1/career-pathfinder)

## 功能与实现

| 功能 | 公开代码与说明中的实现 |
| --- | --- |
| 简历与画像 | 解析 PDF / DOCX / TXT，组织学生画像 |
| 岗位匹配 | 基础要求、技能、素质与发展潜力四维规则，保留确定性打分和约束 |
| 知识检索 | YOUTU-GraphRAG 业务适配、岗位与技能关系检索 |
| Agent 咨询 | 状态机、工具调用、检索与业务规则配合 |
| 报告 | 匹配分析、职业路径与行动计划，支持文档导出 |
| 前后端 | Python / FastAPI；Vue 3 / Vite / Pinia |

## 工程取舍

LLM 用于理解与生成，检索用于提供岗位知识，匹配规则用于统一打分和业务约束。公开版本提供脱敏 Demo 数据，并将本地模型、原始招聘数据和完整 GraphRAG 资产分开管理。

## 运行模式

公开仓库提供脱敏 Demo 数据；完整 GraphRAG 检索需要额外准备模型、图谱、索引和授权数据。功能与启动说明见现有公开代码的 README。
