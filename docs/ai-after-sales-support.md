在小米 AI Native 工程师训练营中完成的团队原型。项目提供用户端与人工客服工作台，连接自动咨询、知识检索、业务判断和真实人工接管。

## 核心设计

**AI 的判断与后台业务动作分别处理。** AI 提出结构化判断；后端校验合法路径并执行状态变更。

| 场景 | 系统行为 |
| --- | --- |
| 普通政策咨询 | 检索知识并回答，继续自助服务 |
| 自由文本描述 | 提出已有流程中的候选路径，经过校验与用户确认 |
| 明确或疑似安全风险 | 创建真实人工接管记录，进入 P0 队列 |
| 权限或能力不足 | 转接人工并交接上下文 |
| 客服处理 | 接单、回复、解决的状态约束与审计留痕 |

## 技术与边界

- 后端：Python / FastAPI；前端：Vue 3 / Vite / Pinia。
- 模型：OpenAI 兼容接口；知识检索：轻量 TF-IDF RAG。
- 原型使用模拟业务数据，Case、Queue 和 Audit 为内存状态。
- 不将该训练营原型描述为生产级订单、支付或退款系统。

## 验证方法

项目采用自动化回归、真实模型路径核验和人工端到端测试，覆盖安全风险、否定语境、非法路径、人工接管和优先级等边界案例。通过实际 Case、Queue、Handoff Packet 和 Audit 检查后台动作，而不只观察 AI 的回复文本。
