# AI售后客服分流系统

面向售后场景，连接自动咨询、知识检索、业务流程、安全判断和人工接管。系统提供用户咨询页面与人工客服工作台，保留交接上下文和业务操作记录。

[查看项目代码](https://github.com/WuJiaxuan1/ai-after-sales-support)

## 项目功能

| 场景 | 系统行为 |
| --- | --- |
| 普通政策与故障咨询 | 检索知识并回答，继续自助服务 |
| 自由文本描述 | 提出已有流程中的候选路径，校验后由用户确认 |
| 明确或疑似安全风险 | 创建真实人工接管记录，进入 P0 队列 |
| 主动找人工、权限或能力不足 | 转接人工并交接此前上下文 |
| 客服处理 | 接单、回复、解决的状态约束与审计留痕 |

## 设计与迭代

- 以确定性 Workflow 为业务骨架，让模型承担理解、检索与结构化判断。
- 为自由文本引入候选路径、合法性校验和用户确认，限制模型直接修改业务状态。
- 调整 RAG 调用时机，修复知识咨询被误转人工的问题。
- 将安全判断与真实人工交接连接起来，核对工单、优先级和客服状态。
- 修复回复暴露内部知识库措辞的问题，并整理实现、测试和维护说明。

## 技术实现

后端采用 Python / FastAPI，前端采用 Vue 3 / Vite / Pinia，模型通过 OpenAI 兼容接口接入，知识检索采用轻量 TF-IDF RAG。

验证时结合用户端和客服端，以及实际 Case、Queue、Handoff Packet 和 Audit 检查后台动作。现有规则回归覆盖安全风险、否定语境、非法路径、人工接管与权限边界等场景；具体检查范围见项目仓库中的验证说明。

## 运行边界

当前使用模拟业务数据，工单、会话与审计信息保存在内存，重启后清空。尚未接入生产级订单、支付或退款系统。
